# Interaction Retrospective

## What the Record Supports

- Which choice affected the outcome? What could the agent know when it made
  that choice, and what became clear only later?
- What did the user accept or correct on this occasion? What behavior and
  scope, if any, did they explicitly ask to carry forward?
- Which observations support the lesson independently, and which comments
  revisit the same decision and outcome?
- What guidance was available at the point of decision? What do the agent's
  words and actions show about how it used that guidance?

## What Carries Forward

- In what later situation would repeating or changing this behavior help?
  In what similar-looking case would a different choice be appropriate?
- What would guidance add at that point? When the work itself has been
  corrected, what evidence suggests that different guidance would have
  changed the agent's original decision?
- Which details let a future agent recognize that decision? What can stay in
  the interaction record once the lesson is expressed in the destination's
  own terms?
- Which source reaches the agent where the decision is made? If none does,
  what recurring need would justify a new one? How much emphasis does the
  lesson deserve alongside the other guidance there?

A lesson without a suitable home can remain a recommendation. The record can
also support leaving existing guidance as it is.
