# Naming

## Meaning in Use

- Where will people encounter the name? What meaning is already supplied by
  its surroundings, and which distinctions must travel with the name when
  it appears elsewhere?
- What does the concept denote in practice? Which term do practitioners use
  for that meaning, and do its implications fit the actual use? Which words
  in the request are exact terms and which express the idea informally?
- Which nearby names might someone confuse with this one? What distinction
  should a reader recognize across the group?
- For a quantity, what does the value represent? Which unit or basis is already
  apparent in use, and which needs to travel with the name?

## Compare Names in Context

- In a representative use alongside its peers, what scope would a reader
  infer from the candidate? How well does that fit what it denotes?
- What would adding or removing a word change about meaning, recognition, or
  ease of finding the name? Who would recognize an abbreviation in that use?
- When a candidate needs several qualifiers, do they express a useful
  distinction or reveal that one term has several meanings? Would renaming
  the shared concept or revising the names together make those meanings
  clearer than a local edit?
- Can each candidate be used in its exact written form on the intended
  surface? Which distinctions survive that form?
- When reviewing an existing name, what does it already convey, and what
  would someone understand more accurately if it changed?
- For a naming system, what distinction does each part encode? When can a part
  be omitted? Try the rule on a plausible new member to see whether it gives
  that member a distinct, intelligible name.
